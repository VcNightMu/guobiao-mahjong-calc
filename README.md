# guobiao-mahjong-calc

国标麻将（中国麻将竞赛规则）算番器。

当前阶段：**听牌算番** —— 输入手牌 + 副露 + 圈风门风，算出听牌张，以及每种和法下的番数。

**技术栈**：Rust（零依赖）。引擎与界面分离；界面先是命令行，后续用 WebView2 包壳出 `.exe`。

## 构建与运行

```bash
cargo build          # 编译
cargo test           # 跑单测
cargo run -- 123456789m 55p 78p --round 东 --seat 东
```

> 提示：MinGW 工具链在含中文的路径下会链接失败（`ld` 打不开 UTF-8 路径），
> 请把工程放在纯 ASCII 路径下。

## 命令行

```
gbmj <手牌> [副露...] [圈门...]

手牌:  13 - 3×副露数 张暗牌，如 123m 456s 789p 东东
副露:  --chi 123m   吃
       --pon 5p     碰
       --kan 5p     明杠
       --ankan 5p   暗杠
圈门:  --round 东   圈风   --seat 南   门风
```

输出：结构听牌张、每种和法（点和 / 自摸 / 点和绝张 / 自摸绝张）的番数，以及够不够 8 番。

## 已锁定的口径

- 只算**手牌番**；花牌完全不参与（不计番，也不参与起和）。
- 不计**偶然番**：抢杠和、海底捞月、妙手回春、杠上开花。
- 和牌方式四种：**点和 / 自摸 / 点和绝张 / 自摸绝张**。
- **门清** = 无吃、无碰、无明杠（**暗杠不算破门清**）：
  - 点和 → 门前清 +2
  - 自摸 → 不求人 +4（不再另计自摸）
  - 绝张 → 在对应方式上再 +和绝张 4
- **无番和**：计入。0 番的副露手按无番和 8 番，且**只对"点和"成立**。
- 展示**不做 8 番过滤**，<8 番也显示。

## 关键陷阱（实现注意）

- 起和判定**非单调**：`{0 → 无番和 8} ∪ {≥8}` 能和，`1..7` 卡死。
- 边张 / 坎张 / 单钓将：要求整手**独听**一种牌才计。
- 绝张依赖外部信息（牌河 / 明面），算番器只能按用户假设，不能自判。
- 不重复原则 = ①拆法搜索取最大 + ②结构性互斥查表。
