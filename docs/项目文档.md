| 术语 | 本工程口径 |
|---|---|

| 门清 | 无吃、无碰、无明杠；**暗杠不破门清**（补杠按明杠处理） |

| 花牌 | 完全不参与（不计番、不参与起和） |
| 偶然番 | 不计（抢杠和、海底捞月、妙手回春、杠上开花） |

| 条件可和 | 可和性**三态标注**之一（**升级 A**，用户 2026-10-11 拍板）：对「绝张假设为真且该手为基础零番的非门清手」，**不判整手不可和**，标注「**条件可和：仅非绝张时可和**」——含义为仅在「该张非绝张」的世界下以点和方式和得；绝张为用户假设（Q7 / C4）而非事实断言，故四栏在该张上全部有效。与 Q8「番数照旧全显示」**不冲突**：三态标注只影响可和性结论的呈现，实际番数（含 <8 番）仍全部显示 |
