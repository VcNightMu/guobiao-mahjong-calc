# guobiao-mahjong-calc

国标麻将（中国麻将竞赛规则）算番器。

当前阶段：**听牌算番** —— 输入手牌 + 副露 + 圈风门风，算出听牌张，以及每种和法下的番数。

## 目标功能

- **听牌状态**：告知可以和什么，以及各和法的番数。
- **起和判定**：8 番起和。
- （后续）**未听牌**：估算到"能起和的和牌"还需要几张牌（靠张向听）。

## 已锁定的口径

- 只算**手牌番**；花牌完全不参与（不计番，也不参与起和）。
- 不计**偶然番**：抢杠和、海底捞月、妙手回春、杠上开花。
- 和牌方式四种：**点和 / 自摸 / 点和绝张 / 自摸绝张**。
- **门清** = 无吃、无碰、无明杠（**暗杠不算破门清**）：
  - 点和 → 门前清 +2
  - 自摸 → 不求人 +4（不再另计自摸）
  - 绝张 → 在对应方式上再 +和绝张 4
- **无番和**：计入。0 番的副露手按无番和 8 番，且**只对"点和"成立**（自摸 +1、绝张 +4 会引入番，反而不到 8）。
- 展示**不做 8 番过滤**，<8 番也显示，四栏番数一眼看清哪种和法够和。

## 关键陷阱（实现注意）

- 起和判定**非单调**：`{0 → 无番和 8} ∪ {≥8}` 能和，`1..7` 卡死。
- 边张 / 坎张 / 单钓将：要求整手**独听**一种牌才计。
- 绝张依赖外部信息（牌河 / 明面），算番器只能按用户假设，不能自判。
- 不重复原则 = ①拆法搜索取最大 + ②结构性互斥查表，两件事都要做。
