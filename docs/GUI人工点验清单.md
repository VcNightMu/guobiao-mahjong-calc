> **来源**：测试 T24 代跑报告 `docs/测试评估报告.md` §二十六（代跑**通过 3 项**、**失败降级 3 项**）。
> 本清单只列**代跑无法覆盖、必须真实鼠标/系统级操作**的剩余项；已通过的 3 项（悬停提示 / 窗口缩放 / 字体在位）**无需重做**。
> **口径**：不引入 UI 自动化框架（`C10`/`Q9` 不变）；本清单为**人眼判定**。

## 前置（一次性，约 30 秒）

```powershell
cd F:\AllCodes\guobiao-mahjong-calc
$env:GBMJ_DEMO=1; .\target\release\gbmj-gui.exe   # 换编号即换夹具；关窗口即退出
```

- **二进制新鲜度（每次自查）**：必须满足 `target\release\gbmj-gui.exe` 的 mtime **≥** 所有 `src/**/*.rs` 的 mtime（`Get-Item` 一看便知）；**不满足就先重建**——陈旧二进制出的是**假证据**（本项目已两次踩坑）。
- **若你之后改过 `src/`**：必须先 `cargo build --release --bin gbmj-gui --features gui` 再截图（**`--features gui` 不可省**——T31 起 `default = []`；另外**陈旧二进制 = 假证据**，本项目已两次踩坑）。
- 夹具速查：`1` 门清 ｜ `2` 带副露 ｜ `3` 脚本化点击 ｜ `5` 双碰听 ｜ `6` dirty 提示 ｜ `9` 仅绝张 ｜ `19` 吃累积中态 ｜ `21` 副露>4 守卫 ｜ `22` 张数不符。

## 项 1 · 副露按钮「真实点击 + 高亮 + 自动复位」

| 步骤 | 期望 |
|---|---|
| 1. `GBMJ_DEMO=1` 启动 | 界面正常，无白屏/乱码 |
| 2. 点【碰】按钮 | 该按钮**高亮**（进入 Pon 模式） |
| 3. 在牌库点 `9筒` | 副露区出现 **`碰 9筒×3`**；【碰】按钮高亮**消失**（自动复位） |
| 4.（可选）点【吃】→ 依次点 `1万`、`2万`、`3万` | 出现 `吃 1万2万3万`，高亮消失 |

**判据**：高亮「出现 → 做完一组即消失」，副露条目文案正确。
**代跑失败原因（背景）**：`PostMessage`/`mouse_event` 对 winit **无效**（截图与基线 sha 全等）⇒ 只能人工点。

## 项 2 · `确认` 按钮「点击后变化」+ DPI / 主题

| 步骤 | 期望 |
|---|---|
| 1. `GBMJ_DEMO=6` 启动 | 结果区显示 **`已修改，点【确认】重新计算`** |
| 2. 点【确认】 | 该提示**消失**；结果区出现四栏番表 |
| 3. 系统缩放调 **125%**（设置 → 系统 → 显示 → 缩放）后**重新启动** GUI | 布局正常、按钮与文字仍可读，无裁切 |

**判据**：点击生效；缩放后不错乱。
**已知对照**（T23/T24 像素证据）：`确认` 按钮禁用态底色的同矩形均值色 —— 启用 `(174,200,227)` → `GBMJ_DEMO=21` `(234,235,237)` 中性灰 → `GBMJ_DEMO=22` `(200,217,234)`。

## 项 3 · `清空` 的「半复位」语义（**5 个观察点**）

`GBMJ_DEMO=19`（吃累积中态：应显示 `吃：1万 5万（再点 1 张）`）→ **点【清空】** → 逐条核：

| # | 观察点 | 期望 |
|---|---|---|
| a | 手牌区 | **清空** |
| b | 吃的进度提示 | **消失** |
| c | 【吃】按钮高亮 | **仍然高亮**（`mode` **不**复位 ← "半复位"的关键） |
| d | 结果区 | **仍旧值**（`analysis` **不**清） |
| e | 圈风 / 门风 | **不变** |

**判据**：a/b **清**，c/d/e **不清**（与源码行为一致；代码层已核，见 §26.1-③）。

## 项 4 · 缺字体场景（**可选 · 高风险，不建议做**）

- 需**管理员**临时改名 `C:\Windows\Fonts\simhei.ttf` 与 `msyh.ttc`，且**必须立即改回**（否则系统其它程序字体异常）。
- 预期：中文退化为方块/默认字体，**不应崩溃**。
- **现状**：**未核实**。正向已验（T24）：两款字体在位、全部截图 CJK **无豆腐块**。
- **建议**：不做；如确要做，先记录原文件名再改名，做完立刻复原并复跑一次 GUI 确认恢复。
