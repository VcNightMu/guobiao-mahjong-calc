## 6. 环境与工具链事实（v0.2.22 §6 全部有效；**本轮新增/强调**）

1. **`cargo` 必须在进程 CWD = 仓库根下跑**（`rust-toolchain.toml` 才生效）；一律 `--no-default-features`。
2. **旧侧二进制按用途分**：`diff-cli` 用 **`555d936`**（修复前，74 条 `diff:` 靠它复现）；`diff-tables` 用 **`2a7d259`**（且 debug/release **各真跑一份**）。**不得用同 HEAD 两构建**做"行为变化"类对照（会全部退化成 `same`）。
3. **捕获原生命令输出必须走「重定向到文件 + 噪声剥离」**（PS 会把**调用点脚本行号**与源码回显包进 stderr ⇒ 指纹随脚本改动漂移）。参考实现：`scripts/diff-cli.ps1`（9 条模式 + 3 个 Base64 中文常量）。
4. **"证据 provenance 必须为真"**：`-debug` / `-release` 两档必须**各自真跑**；把一档结果复制成另一档 = 假证据（本轮 T89 真实发生过，已返工）。
5. **"内容护栏 ≠ 差分"**：`diff:` 型差分**不构成**内容护栏（预期就是"有差异"）⇒ 要守住某个输出行为，必须**金标准逐字**（如 `docs/BASELINE_diag-switches.txt`）。
6. **编码体检**：**必须**用 `read` 工具或 `[System.IO.File]::ReadAllText`（UTF-8）/严格解码；**`Get-Content` 在本机按 ANSI 解码**，会把正常中文读成乱码 ⇒ 本轮 Lead 的覆盖自检**误报 4 手大四喜"不在语料"**（真实全部在）。
7. **测试耗时受机器负载影响明显**（并行构建时 8.3–9.1 s vs 空闲 6.4–7.0 s）⇒ **不要用单次耗时做回归判据**。
8. **`只增不裁`的语料**：语料手数只增（50→55→57），方向数 216→236→256；`total_dirs >= 130` 阈值**不要**随实际值上调（否则护栏退化成快照）。
9. 其余沿用：门禁脚本纯 ASCII（`>127=0`、`CR=0`；中文走 Base64 或数据文件）、`Measure-Object -Line` 只数非空行、`$ErrorActionPreference='Stop'` + 原生 stderr 的坑、debug sha 含路径、`.NET` 静态 API 按进程 CWD 解析相对路径、修订 18 并发 `target/` 争用、`git worktree` 用完 `remove --force`。

## 9. 诚实边界（**不要当成已闭环**）

- **`diff-tables` 的取舍（已写死）**：`diff:<理由>` 在**当前 binary-pair** 下未出现差异时记 `same/same-whole` 且**不报警**（否则换 pair 会全红）⇒ **"修复被反向撤销"不会被它发现**；脚本头 `known limitation` 已写明。
- **`reason` 列不保证描述当前 pair 的真实差异类别**（它回显语料期望，相对修复前构建登记）。实例：`plan-dump-cross-four-kans` 在 `2a7d259` 下的差异实为 F2/T75 家族（因 `2a7d259` **已含** `--dump-tables`）。
