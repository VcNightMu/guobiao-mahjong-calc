## 3. 接口与数据结构改动

### 3.1 `WinCtx` 增字段（R-02）
```rust
// src/fans.rs:35-47
pub win_completes_triplet: bool,  // 荣和这张牌把手中已有对子补成刻子
```
赋值点 `src/calc.rs:204-214` → `concealed[t] == 2`（`concealed` 为加和牌张之前的暗牌）。等价性：加张后暗牌恰含 3 张 `t`，`==2` ⇔ 和牌张补成了该刻子 ⇔ 荣和应降级为明刻；`==3` ⇔ 刻子早已成型（和牌张进顺子/将）⇔ 仍是暗刻。

### 3.2 可和判定：三态（R-01 + 新-2，`src/calc.rs`）
```rust
pub enum WinVerdict { Win, ConditionalLast, NoWin }

impl WaitResult {
    // N/T 恒适用（不被 g_last 门控）；L/TL 仅当 g_last 时适用
    pub fn verdict(&self) -> WinVerdict {
        let nt_ok   = self.normal >= 8 || self.tsumo >= 8;
        let last_ok = self.can_last && (self.last >= 8 || self.tsumo_last >= 8);
        if last_ok { WinVerdict::Win }
        else if nt_ok && self.can_last { WinVerdict::ConditionalLast }
        else if nt_ok { WinVerdict::Win }
        else { WinVerdict::NoWin }
    }
    pub fn can_win(&self) -> bool { matches!(self.verdict(), WinVerdict::Win) } // 薄封装
}
```
- **三态**：`Win`「可和」；`ConditionalLast`「条件可和：仅非绝张世界，点和」；`NoWin`「不可和」。
- **关键用例（新-2 要求）**：`g_last=true` 且 base=0 的非门清手（N=无番和8、T=1、L=4、TL=5）→ `last_ok=false`、`nt_ok=true` ⇒ **`ConditionalLast`**（既不是不可和，也不是无条件可和）✓。
- Q3 保留：四种方式全受限（`!nt_ok && !last_ok`）⇒ `NoWin` ✓。
- `can_last` **保持 `concealed[t]==0`**（R-03 撤销 / C4），仅改 `:84-85` 注释。
- 兼容：`WaitResult` 字段、四栏数值、`fans`/`fans_tsumo`、`--plan` 输出格式不变。`only_tsumo()`/`only_last()` 需与新三态对齐（`main.rs:140-146`、`gbmj_gui.rs:435-441` 仍在用；精确改法执行时以实读为准）。

## 4. 逐条实现思路

### 4.1 R-02 / D-2 —— 荣和暗刻误判（缺陷 A）
`:322` 追加 `&& !ctx.win_completes_triplet`（字段与赋值见 3.1），同步 `:310`/`:323` 注释。效果：`111m 23m 456m 999s 55p` 荣和 1万（`concealed[1m]==3`）→ 补 `双暗刻2`，点和 8→**10**、点和绝张 12→**14**；自摸两栏不变。

### 4.2 R-01 / D-1 + 新-2 —— 可和判定三态
按 3.2 实现 `WinVerdict` 与 `verdict()`；按 3.8 落地 CLI/GUI 文案。三态判定核对：①四种方式全受限 → `NoWin`（Q3）；②`g_last=true`、base=0 非门清（N=8/T=1/L=4/TL=5）→ `ConditionalLast`（新-2 核心）；③`g_last=false` 且 `nt_ok` → `Win`（N/T 不被 `g_last` 门控）；④`g_last=true` 且 `last_ok` → `Win`。

### 4.3 R-11（扩围后）—— 组合龙分支补齐杠系 + 刻子类番
**新实现**：按 3.5 抽共用函数并两处调用；`Special::Zuhelong` 臂内统计基 = `d.sets + ctx.melds`（`m==1` 时 `d.sets` 为空，只有副露那一副面子；`m==0` 时第四副面子在 `d.sets` 内）。

**逐族评估（不会误触发/重复计番）**
| 族 | 组合龙分支 | 依据 |
|---|---|---|
| 碰碰和 6 | **永不触发** | 组合龙含 3 副顺子 → `all_trips=false` |
| 暗刻类（双/三/四暗刻） | **永不触发** | 9 张本体无刻子，最多第 4 副面子 1 个 → `concealed_trips ≤ 1` |
