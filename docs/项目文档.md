## 1. 项目范围与目标

### 1.1 本轮目标
在**不新增功能**的前提下，把项目从「引擎测试全绿」推进到「**正确性可信 + 有测试兜底 + 文档与实现一致**」，交付一个可交付、可验收的稳定版本，具体三件事：

1. **收口已确认缺陷**：修复已确认的 **6 个**计番/健壮性缺陷（R-01、R-02、R-04、R-05、**R-11**、**R-12**；原 R-03 经用户 2026-10-11 裁决**撤销**、不计入），并保证修复不引入回归。
2. **补足测试兜底**：为已确认缺陷建立回归用例；对**当前零覆盖的番种**按优先级建立覆盖。
3. **文档与实现对齐**：让 README 与源码中的说明反映真实实现，接手者不再被误导。

### 1.2 本轮**不做**（明确边界，防止范围蔓延）
- 不做新番种算法研究、不做番种表扩张。
- 不做界面视觉打磨（布局留白、牌面图形化）、不做新交互功能。
- 不做性能优化与基准测试。
- 不做重构式改动；**Q10 允许小范围重构**，但**仅限 3 处**（C8/C9 细化）且必须在开发方案中注明范围（视为范围明确的受控改动，不是自由重构）。
- 不做覆盖兜底的第 2 批及以后：本轮 R-07 **只做批 1**，其余批次全部转下轮（A6）。
- 不引入 GUI 自动化测试框架（Q9=A：GUI 验收接受人工点验记录）；GUI 自动化测试与质量门禁**均放下一轮**（C10，与 Q6 一致）。
- 不引入 CI / 质量门禁配置，不做仓库清理（**Q6 改裁：R-10 本轮不纳入**，转下轮候选）。
- 不修「幻影结构听牌」（A2）：用户 2026-10-11 裁决其**视为听牌**（只是听 0 张），**不算缺陷**；任何人不得再以此立项或上报 bug。

## 10. 术语与口径统一（本工程已锁定口径，PM 仅作一致化，不改口径）

| 术语 | 本工程口径 |
|---|---|
| 听牌 / 结构听牌 | 「结构听牌」= 存在和牌型的候补张（未必够 8 番）；展示不做 8 番过滤 |
| 四种和牌方式 | 点和、自摸、点和绝张、自摸绝张；**绝张两栏为假设性展示，四栏在该张上全部有效**（升级 A） |
| 起和门槛 | 非单调：`{0 → 无番和 8}` 与 `{≥8}` 可和，`1..7` 卡死 |
| 无番和 | 仅对「点和 + 非门清 + 零番」成立，计 8 番 |
| 门清 | 无吃、无碰、无明杠；**暗杠不破门清**（补杠按明杠处理） |
| 绝张 | 定义：**牌池与副露区已出现 3 张**（第 4 张为绝张）；**手上的牌一定不是绝张**（C4）；算番器按用户假设输入，不自动判定（Q7 不变）；**绝张为假设而非事实断言 ⇒ 四栏在该张上全部有效**（升级 A） |
| 边张 / 坎张 / 单钓将 | 仅当整手**独听**一种牌时才计 |
| 花牌 | 完全不参与（不计番、不参与起和） |
| 偶然番 | 不计（抢杠和、海底捞月、妙手回春、杠上开花） |
| 不重复原则 | ①拆法搜索取最大；②结构性互斥查表 |
| 幻影结构听牌 | 和牌张与自家暗杠同号的结构听牌**视为听牌**（仅听 0 张）；用户 2026-10-11 裁决：**不算缺陷、不修**（A2），后续不得重复报为 bug |
| 手牌张数公式 | 手牌张数＝`13 − 3n`，n 为**副露区面子数**，面子**可为杠**；**四杠合法**（C6） |
| 单张计数 | 「同一张 ≤4」为**全局计数**：暗牌＋副露＋杠合计（C7） |
| 番种互斥（补充规定） | **字一色不计混幺九；全大不计大于五；全小不计小于五**（R-12，用户明确规定的口径） |
| 退出码 | **0＝成功；2＝用法或输入错误**；无参数时显示用法；解析出 0 张牌 → 报错退出（C1/C2） |
| 条件可和 | 可和性**三态标注**之一（**升级 A**，用户 2026-10-11 拍板）：对「绝张假设为真且该手为基础零番的非门清手」，**不判整手不可和**，标注「**条件可和：仅非绝张时可和**」——含义为仅在「该张非绝张」的世界下以点和方式和得；绝张为用户假设（Q7 / C4）而非事实断言，故四栏在该张上全部有效。与 Q8「番数照旧全显示」**不冲突**：三态标注只影响可和性结论的呈现，实际番数（含 <8 番）仍全部显示 |
